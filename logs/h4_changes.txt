=== 2026-10-24T05:52:18Z  P1 analysis definitions, fixed BEFORE any shared-GPU data exists or any fit is run ===
- L_iso for a shared cell (model m, small_share, max_tokens, concurrency) = median over repeats of the
  separate-placement p50 (p95 for the p95 fits) in the same (m, small_share, max_tokens, concurrency) cell.
- "total requests in flight" in B1 = the concurrency level of the cell.
- Fits: scipy least_squares on log latency, all parameters bounded >= 0; bootstrap CIs: 1000 resamples
  of fit cells, numpy default_rng(0). Concurrency-1 cells are excluded from fitting, kept in MAPE.
- MAPE: mean |pred - measured| / measured over every held-out (cell, model), concurrency 1 included.
- Direction accuracy (judged number): over held-out (small_share, max_tokens, concurrency) conditions with
  concurrency >= 4, measured slowdown = shared p50 / L_iso averaged over the held-out repeats; a tie in
  the predicted slowdowns counts as wrong. Reason: at concurrency 1 there is no overlap, so every model
  predicts identical slowdowns for both models and the criterion would be decided by this evaluation
  choice, not by the data. The all-conditions number (concurrency 1 included) is reported as well.

=== 2026-10-24T05:57:51Z  P4 measurement definitions, fixed BEFORE P4 runs ===
- Per run (placement, K, repeat): p50/p95 of the 64 per-problem end-to-end latencies; problems per
  GPU-hour = 64 / (last end - first start, in hours) / GPUs (S=2, C=1, CM=1); accuracy = mean correct.
  Reported numbers are means over the 2 repeats.
- Goal check uses K=16: placement P meets it if mean p95(P) <= 1.5 x mean p95(S). The "actual best" is
  the 1-GPU placement (C or CM) that meets it with the lower p95, else S. A recommendation is "correct"
  if it equals the actual best. Prediction error = predicted p95 / mean measured p95 - 1 at K=16.
